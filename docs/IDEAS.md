# Ideas y bocetos (no implementado)

## Decidido para el músculo
- El modelado visual del músculo usa el mismo sistema que la grasa: mismas zonas y mismo volumen.
- La masa de la zona útil (grasa 1 a 4) se tonifica según el nivel de músculo. La de la zona pura (5 a 7) nunca.
- Panza: abdominales y pectorales. Nalgas: tonificación. Brazos: crecen solo con el músculo.
- Se hace por pasos: primero panza, se prueba, después nalgas y brazos.
